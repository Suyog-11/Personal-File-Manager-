## 🎨 Customization

To customize colors, edit the gradient in `styles.css`:

```css
.auth-container {
  background: linear-gradient(135deg, 
    #667eea 0%,      /* Change this color */
    #764ba2 25%,     /* Change this color */
    #f093fb 50%,     /* Change this color */
    #4facfe 75%,     /* Change this color */
    #00f2fe 100%     /* Change this color */
  );
}
```
